# Impact4Kidz Website

This repository hosts the public website for **Impact4Kidz NFP** at **www.impact4kidz.org**.

## Purpose

Impact4Kidz supports education and workforce development by creating technology programs and services that provide high school and college students with practical experience in IT, cybersecurity, software development, and related fields.

The organization also provides fundraising tools and affordable technology services to educational programs, including reduced-cost access for organizations serving low-income and underserved communities.

## Projects

### GradVids
GradVids is a DBA of Impact4Kidz and the name of the organization's fundraising platform. It enables supporters to make donations while sending custom, personalized congratulatory video messages to recent graduates.

### Parkoach
Parkoach is a real-world technology project used to provide practical student experience in software development, cloud infrastructure, security, data, and product operations.

## Hosting

This is a static site intended for GitHub Pages. The custom domain is configured through the repository's `CNAME` file.

## Development

No build system is required. The site can be previewed by opening `index.html` in a browser.
